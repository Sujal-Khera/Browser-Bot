# Product

## Register

product

## Platform

web

## Users

* **Developers and AI engineers**: Wanting to wrap repetitive browser tasks into clean, Claude-compatible MCP servers. They value speed, transparency in code generation, and direct control over parameters.
* **Non-technical operators**: Needing an intuitive, wizard-driven local browser recorder. They value visual feedback, step-by-step guidance, and clear error recovery.

## Product Purpose

BrowserBot compiles recorded local browser play-throughs into production-ready MCP tool servers. It exists to remove the friction of manual scraper coding while preserving local-first privacy, security sandboxing, and timing resilience. Success looks like compiling a fully validated, self-healing browser tool and installing it into Claude Desktop in under 2 minutes.

## Positioning

Local-first developer workflow simplicity: Creating MCP servers in under 2 minutes with no cloud lock-in.

## Brand Personality

* **Voice/Tone**: Minimalist, developer-first, high-fidelity utility.
* **3-Word Personality**: Focused, robust, precise.
* **Emotional Goals**: Instill confidence in generated outputs, feel lightweight, and behave transparently.

## Anti-references

* Generic Bootstrap or admin dashboard templates with repetitive cards, excessive tables, and multi-level nested sidebars.
* Over-stylized "AI futuristic" dark themes with poor contrast, neon gradients, or glassmorphism that reduces readability.
* Marketing-style parallax scroll animations or excessive loader delays that slow down task completion.

## Design Principles

1. **Step-by-Step Flow Clarity**: The stepper is the central guide; the user always knows their current stage and the exact requirements to progress.
2. **Immediate feedback & diagnostics**: Expose compilation, validation, and CLI outputs in clean monospace panels immediately to avoid a "black-box" feel.
3. **Frictionless keyboard defaults**: Form inputs, action buttons, and parameters should default to logical keyboard focus and submit behaviors to optimize speed.

## Accessibility & Inclusion

* Full WCAG 2.1 AA compliance with high-contrast text and explicit keyboard focus rings.
* Strict support for `prefers-reduced-motion` media queries.
* Multi-modal indicators: Never convey state (success/error/warning) using color alone; always accompany status colors with descriptive text and clear icons.
* Desktop-centric responsive layouts (scalable to 200% zoom without horizontal clipping).
