# Non-Functional Requirements

| Requirement | Target | Measurement Method |
|-------------|--------|--------------------|
| **Generation Time** | Recorder stop → installable MCP tool ≤ **3 minutes** | Time the complete pipeline from stopping the recording to a validated, installable MCP package using a stopwatch or automated timer. |
| **Runtime Latency** | Claude request → final response ≤ **20 seconds** (target: 15 seconds) | Execute the generated tool 10 times under normal network conditions and calculate the average end-to-end response time. |
| **Reliability** | **≥ 8 successful executions out of 10** (80% minimum success rate) | Run an automated 10-iteration validation script and record successful end-to-end executions without manual intervention. ≥ 90% success rate during deterministic validation (minimum 9/10). |
| **Privacy** | **No credentials, passwords, authentication tokens, or PII are persisted** to disk | Inspect generated logs, session files, configuration files, and outputs. Verify sensitive values are redacted or replaced with placeholders (e.g., `__SECRET_1__`). |
| **Local-first Execution** | Browser automation, recordings, generated code, and validation execute **entirely on the local machine**. With the default Ollama backend, **zero data leaves the machine**, including LLM inference. If the optional Groq free-tier fallback is enabled, only the minimal prompt payload leaves the machine; it must never include raw credentials or PII. | Verify system architecture and inspect network traffic during execution. Default Ollama path: confirm no outbound LLM requests occur. Groq fallback path: confirm only the approved Groq endpoint receives requests, and that payload never contains scrubbed secrets. |
| **Cost Ceiling** | **$0 total cost** — no step in the pipeline, from Phase 0 through Phase 10, may require a credit card or a paid API account to complete end-to-end. The Ollama LLM backend is the default ($0 marginal cost). The Groq free-tier is the documented fallback (also $0, no card required). | Verify that the default configuration requires no API key or account: `env | grep -i api_key` returns nothing. If the Groq fallback is configured, confirm its key lives only in a git-ignored `.env` file, never committed or embedded in any generated artifact. |
| **Reproducibility** | Fresh operating system environment (Windows/Linux/macOS or Docker container) can set up and execute the project successfully without manual fixes | Clone the repository into a clean environment, install dependencies, run the setup instructions, and verify that the demo pipeline completes successfully. |
| **Determinsm** | Given the same recorded workflow and confirmed parameters, the generated tool should produce functionally equivalent behavior across repeated generations. | Generate the tool 5 times from the same recording and verify all generated tools successfully complete the workflow without manual modification. |

---

## Acceptance Criteria

The BrowserBot MVP will be considered to satisfy its non-functional requirements only if **all** of the following conditions are met:

- Generation pipeline completes within **3 minutes**.
- Average runtime latency remains below **20 seconds**.
- At least **9 out of 10** consecutive executions succeed.
- No credentials or personally identifiable information are stored in any generated artifacts.
- With the default Ollama backend, zero data leaves the local machine at any point in the pipeline, including LLM inference. If the Groq fallback is active, only the scrubbed prompt payload leaves the machine.
- The entire pipeline completes end-to-end with **$0 spent** — no credit card or paid API account is required at any step.
- A clean environment can reproduce the project using only the documented installation steps.

## Verification Strategy

| Requirement | Verification |
|--------------|--------------|
| Generation Time | Measure total pipeline execution time during end-to-end testing. |
| Runtime Latency | Benchmark 10 consecutive Claude invocations and compute average latency. |
| Reliability | Execute an automated reliability test script (`10` consecutive runs) and calculate the success rate. |
| Privacy | Perform a credential and PII audit across generated logs, JSON files, caches, and temporary artifacts. |
| Local-first Execution | Default path (Ollama): confirm zero outbound network requests to any LLM endpoint. Fallback path (Groq): confirm only the Groq endpoint receives requests and payload contains no raw secrets. |
| Cost Ceiling | Verify the default configuration completes without any API key: `env \| grep -i api_key` returns nothing. If Groq fallback is configured, confirm its key is in a git-ignored `.env` file only. |
| Reproducibility | Validate the project on a clean virtual machine or container following only the documented setup instructions. |
