# BrowserBot Requirements

## Problem Statement

Developing browser automation tools for AI assistants is repetitive, fragile, and requires significant manual engineering. Developers must hand-write Playwright scripts, expose them as MCP tools, validate them, and package them before they can be used by Claude Desktop. BrowserBot eliminates this manual process by recording a single browser workflow once and automatically generating a validated, installable MCP tool that Claude can invoke through natural language.

---

## Elevator Pitch

BrowserBot records a browser workflow once and automatically generates a validated, installable MCP tool that Claude Desktop can execute using natural language.

---

## Target User

**Primary User**

AI developers and GenAI engineers who want to create custom browser automation tools for Claude Desktop without manually writing Playwright automation or MCP server code.

---

## Locked Demo Scenario

**Website:** Mock Order Tracking Portal (authenticated demo website)

**Workflow:**

1. Open website
2. Log in using demo credentials
3. Enter an Order ID
4. Submit the lookup form
5. Read the displayed shipment status
6. Return the result through Claude

This is the **only** workflow supported in the MVP.

---

## Success Story

```
User:
"Claude, did my order ship?"

↓

Claude identifies the generated BrowserBot MCP tool

↓

BrowserBot launches the browser

↓

Logs into the demo website

↓

Enters the provided Order ID

↓

Retrieves the shipment status

↓

Returns:

"Order #12345 shipped yesterday via FedEx. Expected delivery: July 14."
```
